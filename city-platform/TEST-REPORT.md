## 1. 测试策略

### 1.1 测试范围

| 模块 | 包含 | 不包含 |
|------|------|--------|
| GIS 地图可视化 | 底图加载、缩放平移、300 个部件点位渲染、Marker 样式、Popup 信息窗 | 真实瓦片服务切换、离线地图 |
| 图层管理 | 5 大类图层开关、按类别/状态/区域筛选 | 自定义图层叠加、WMS/WFS 服务 |
| 部件 CRUD | 新增、编辑、删除部件（含坐标落点） | 批量导入/导出部件 |
| RBAC 权限 | 4 角色（城管局/园林局/环卫局/交通委）菜单和数据隔离 | 细粒度字段级权限 |
| 空间查询 | 点选、框选、缓冲区查询 | 多边形自定义查询、拓扑分析 |
| 空间量算 | 距离测量、面积测量 | 方位角、高程 |
| 操作日志 | 按时间/操作人/模块筛选查看 | 日志归档、审计报表 |
| 统计图表 | 部件分类统计、状态统计、区域分布 | 自定义报表生成 |
| 数据导出 | 空间查询结果 CSV 导出 | Excel/GeoJSON 导出 |

### 1.2 测试类型与占比

| 测试类型 | 占比 | 说明 |
|----------|------|------|
| 功能测试 | 60% | 核心业务流程与功能验证 |
| UI/UX 测试 | 15% | 界面布局、交互体验 |
| 数据验证 | 10% | 测试数据正确性与完整性 |
| 兼容性测试 | 10% | 多浏览器、多分辨率 |
| 性能测试 | 5% | 地图渲染、大数据量交互响应 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 浏览器 | Chrome 120+, Firefox 125+, Edge 120+ |
| 分辨率 | 1920×1080（桌面）, 1366×768（笔记本）, 375×812（移动端） |
| 网络 | 本地演示环境（localhost） |
| 测试数据 | 300 个部件点位, 17 子类别, 5 大类 |
| 测试角色 | 城管局 / 园林局 / 环卫局 / 交通委 |

### 1.4 优先级定义

| 级别 | 标记 | 定义 |
|------|------|------|
| P0 | 🔴 | 阻塞性缺陷，核心功能不可用，必须在上线前修复 |
| P1 | 🟠 | 高优先级，严重影响用户体验或数据正确性 |
| P2 | 🟡 | 中优先级，功能可用但有瑕疵 |
| P3 | 🟢 | 低优先级，建议改进项 |

## 3. UI / UX 测试

### 3.1 界面布局检查

| 检查项 | 检查点 | 预期标准 |
|--------|--------|----------|

| 侧边栏 | 菜单层级、展开/折叠、图标含义 | 菜单层级 ≤ 3 层，图标与文字含义一致，展开折叠动画流畅 |
| 图层控制面板 | 位置、复选框样式、筛选下拉 | 面板不遮挡地图操作区域，复选框状态清晰，下拉菜单可正常展开 |
| 详情面板 | 字段排列、照片区域、操作按钮 | 字段标签对齐，按钮主次分明（保存/确认为主要按钮，取消为次要按钮） |

| 浏览器兼容性 | 低 | 老旧浏览器可能不支持 ES6/Canvas | 明确支持的最低浏览器版本，使用 Polyfill |
| CSV 导出乱码 | 中 | 中文在 Excel 中直接打开可能乱码 | CSV 添加 BOM 头 (`\uFEFF`) |
