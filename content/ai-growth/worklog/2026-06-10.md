## 事件三：模型切换问题修复

**事项**
用户发现模型从 deepseek-v4-pro 自动切换成了 doubao-seed-2.0-pro，要求排查并修复。

**进展**
- 排查配置发现 deepseek 的 API 类型错误配置为 `openai-completions`（应为 `openai-chat`）
- DeepSeek 不支持旧版 Completions 接口 → OpenClaw 自动 fallback 到第一个备选 doubao
- 修改配置文件为 `openai-chat`，重启 gateway 生效

**经验或教训**
- 配置文件字段类型要严格对照 API 规范，一个小差异就导致模型不可用
- fallback 机制默默兜底，用户感知到模型变差才知道出了问题
- 受保护的配置路径不能通过 config.patch 修改，需直接编辑 JSON 文件

**Sunny的建议**
建议定期检查当前模型，或在 HEARTBEAT 里加一条"模型健康检查"。
