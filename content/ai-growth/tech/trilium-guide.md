## 二、Trilium 是什么？

Trilium Notes 是一个**树形层级个人知识库**，开源免费（AGPL 协议），GitHub 28K+ Star。

**核心定位：** 不是又一个 Markdown 编辑器，而是一个**知识管理中枢**——所有笔记以树形结构组织，支持无限嵌套、双向链接、关系图谱、全文搜索、脚本自动化。

### 与普通笔记工具的区别

| 特性 | 普通笔记（如备忘录） | Trilium |
|------|---------------------|---------|
| 组织方式 | 平铺列表 | **树形层级**，无限嵌套 |
| 关联能力 | 无 | **关系图谱**，双向链接 |
| 检索 | 标题搜索 | **全文检索** + 标签过滤 |
| 自动化 | 无 | **内置脚本引擎**，自定义工作流 |
| 数据归属 | 云端 | **自托管**，数据完全归你 |
| 多端访问 | 取决于服务 | Web + 桌面客户端同步 |

## 三、核心功能

### 3.1 树形笔记组织

笔记以树形结构排列，可以无限嵌套子节点。结构示意如下：

```
📁 工作
  ├── 📁 项目方案
  │   ├── 📄 智能体协同方案
  │   ├── 📄 数据要素方案
  │   └── 📄 AI 应用方案
  ├── 📁 会议记录
  │   ├── 📄 2026-06-02 周会
  │   └── 📄 2026-05-28 复盘
  └── 📁 行业调研
      ├── 📄 AI Agent 趋势
      └── 📄 政务信息化政策
📁 学习
  ├── 📁 AI 技术
  ├── 📁 产品方法论
  └── 📁 读书笔记
📁 生活
  ├── 📁 旅行计划
  └── 📁 健康记录
```

### 3.2 笔记类型

Trilium 支持多种笔记类型，右键节点可选择：

| 类型 | 用途 | 特点 |
|------|------|------|
| 📝 文本笔记 | 日常记录 | 富文本 + Markdown 混用 |
| 💻 代码笔记 | 代码片段 | 语法高亮 |
| 📊 表格 | 结构化数据 | 类似 Excel |
| 🖼️ 文件 | 附件管理 | 图片、PDF 等 |
| 🔗 关系图 | 知识图谱 | 可视化关联 |
| 📖 书本笔记 | 长文档 | 章节自动拆分 |
| 🎨 画布 | 自由绘图 | 思维导图风格 |

### 3.3 双向链接与关系图谱

在笔记中输入 `@` 或 `Ctrl+L` 可以创建到其他笔记的链接。所有链接关系自动形成**知识图谱**，点击任意笔记的「关系图」按钮即可可视化查看。

这个功能的价值：当你积累了几百条笔记后，关系图谱能帮你发现"原来 A 和 B 有关联"——这是平铺列表做不到的。

### 3.4 全文搜索

Ctrl+S 或点击搜索框，输入关键词即可在所有笔记中全文检索。支持正则表达式。

### 3.5 脚本自动化

Trilium 内置 JavaScript 脚本引擎，可以编写自动化规则。例如：
- 自动为特定标签的笔记设置提醒
- 每天自动生成日记模板
- 批量修改笔记属性

### 3.6 版本历史

每次修改自动保存历史版本，出错了可以随时回滚。

## 四、日常使用流程

### 4.1 快速记录

1. 打开浏览器访问知识库
2. 在左侧树中选中要添加笔记的节点
3. 按 `Enter` 创建子节点，或 `Ctrl+O` 搜索并跳转
4. 开始写内容

### 4.2 组织整理

**建议的组织原则：**

- 第一层：按领域分类（工作 / 学习 / 生活）
- 第二层：按项目或主题分类
- 第三层：具体笔记
- 不要超过 4 层深度

**标签系统：** 在笔记属性面板中添加标签，可以跨树形结构检索。标签命名建议用短横线连接，如 `ai-agent`、`weekly-review`。

### 4.3 日/周记模板

推荐在「日志」节点下按日期创建日记：

```
📁 日志
  ├── 📁 2026-06
  │   ├── 📄 06-01
  │   ├── 📄 06-02
  │   └── ...
  └── 📁 2026-05
```

每天记录：今天做了什么、学到了什么、明天要做什么。

### 4.4 知识提炼流程

```
碎片信息（网页/对话/灵感）
  → 快速录入 Trilium（临时节点）
  → 定期整理（每周日）
  → 归类、合并、关联
  → 形成结构化知识
```

## 五、快捷键速查

| `F5` | 重新加载树 |

## 六、备份与安全

### 自动备份

Trilium 数据存储在服务器的 `/opt/trilium-data/` 目录，建议定期备份：

```bash
# 手动备份
tar -czf trilium-backup-$(date +%Y%m%d).tar.gz /opt/trilium-data/

# 设置 crontab 每周自动备份
0 3 * * 0 tar -czf /opt/backups/trilium-$(date +%Y%m%d).tar.gz /opt/trilium-data/
```

### 密码保护

首次登录后，在右上角「选项」→「密码」中设置登录密码，保护知识库安全。

## 八、常见问题

**Q: 数据存在哪里？**
A: 服务器 `/opt/trilium-data/`，完全归你控制。

**Q: 能多人协作吗？**
A: 当前部署为单用户模式。如需多人，需要额外配置。

**Q: 手机能访问吗？**
A: 可以！手机浏览器打开 `http://82.157.103.93:3002`，界面自适应。

**Q: 会丢失数据吗？**
A: 数据实时写入磁盘，还有自动备份机制。建议定期手动备份一份到其他地方。
