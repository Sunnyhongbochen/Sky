# 声迹知识库交付说明

## 交付内容

本工程是一套可实际运行的单用户录音知识管理网站，包含：

- 手机录音上传、播放、删除和元数据修改
- 本地 Whisper 语音转文字
- 同一说话人连续片段合并显示
- 优化整理稿与六类知识整理模板
- 通用 Chat Completions 模型接口
- 录音、逐字稿、整理稿和知识字段检索

## 运行架构

```text
浏览器 → Node.js 服务 → data 持久化目录
                    ├─ faster-whisper 本地转写
                    └─ 通用大模型接口整理文本
```

这不是纯静态网页。个人网站服务器需要支持长期运行 Node.js 进程，并为 `data` 目录提供持久化存储；如需在服务器执行本地转写，还需要 Python 3.10+ 和足够的内存、磁盘空间。

## 交付包安全边界

交付包不包含以下内容：

- 真实录音文件
- 真实逐字稿和整理结果
- 本机 Whisper 模型缓存
- API Key 或本机加密配置
- Python 虚拟环境

部署后首次启动会自动创建空数据库。模型凭证应通过服务器的密钥或环境变量管理功能注入，不要写入代码仓库。
