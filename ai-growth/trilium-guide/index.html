二、Trilium 是什么？

Trilium Notes 是一个树形层级个人知识库，开源免费（AGPL 协议），GitHub 28K+ Star。

核心定位： 不是又一个 Markdown 编辑器，而是一个知识管理中枢——所有笔记以树形结构组织，支持无限嵌套、双向链接、关系图谱、全文搜索、脚本自动化。

与普通笔记工具的区别

特性普通笔记（如备忘录）Trilium
组织方式平铺列表树形层级，无限嵌套
关联能力无关系图谱，双向链接
检索标题搜索全文检索 + 标签过滤
自动化无内置脚本引擎，自定义工作流
数据归属云端自托管，数据完全归你
多端访问取决于服务Web + 桌面客户端同步

Trilium 支持多种笔记类型，右键节点可选择：

3.3 双向链接与关系图谱

在笔记中输入 @ 或 Ctrl+L 可以创建到其他笔记的链接。所有链接关系自动形成知识图谱，点击任意笔记的「关系图」按钮即可可视化查看。

这个功能的价值：当你积累了几百条笔记后，关系图谱能帮你发现"原来 A 和 B 有关联"——这是平铺列表做不到的。

3.4 全文搜索

Ctrl+S 或点击搜索框，输入关键词即可在所有笔记中全文检索。支持正则表达式。

3.5 脚本自动化

Trilium 内置 JavaScript 脚本引擎，可以编写自动化规则。例如：

  • 自动为特定标签的笔记设置提醒
  • 每天自动生成日记模板
  • 批量修改笔记属性

3.6 版本历史

每次修改自动保存历史版本，出错了可以随时回滚。

四、日常使用流程

4.1 快速记录

  1. 打开浏览器访问知识库
  2. 在左侧树中选中要添加笔记的节点
  3. 按 Enter 创建子节点，或 Ctrl+O 搜索并跳转
  4. 开始写内容

4.2 组织整理

建议的组织原则：

  • 第一层：按领域分类（工作 / 学习 / 生活）
  • 第二层：按项目或主题分类
  • 第三层：具体笔记
  • 不要超过 4 层深度

标签系统： 在笔记属性面板中添加标签，可以跨树形结构检索。标签命名建议用短横线连接，如 ai-agent、weekly-review。

六、备份与安全

自动备份

Trilium 数据存储在服务器的 /opt/trilium-data/ 目录，建议定期备份：

2
3
4
5

# 手动备份
tar -czf trilium-backup-$(date +%Y%m%d).tar.gz /opt/trilium-data/

# 设置 crontab 每周自动备份
0 3 * * 0 tar -czf /opt/backups/trilium-$(date +%Y%m%d).tar.gz /opt/trilium-data/

密码保护

首次登录后，在右上角「选项」→「密码」中设置登录密码，保护知识库安全。

八、常见问题

Q: 数据存在哪里？ A: 服务器 /opt/trilium-data/，完全归你控制。

Q: 能多人协作吗？ A: 当前部署为单用户模式。如需多人，需要额外配置。

Q: 手机能访问吗？ A: 可以！手机浏览器打开 http://82.157.103.93:3002，界面自适应。

Q: 会丢失数据吗？ A: 数据实时写入磁盘，还有自动备份机制。建议定期手动备份一份到其他地方。
